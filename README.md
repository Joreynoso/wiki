# Wiki Personal

Es una enciclopedia personal de contenidos y conceptos.

Este repositorio sirve como un espacio centralizado para documentar, estructurar y consultar rápidamente información relacionada con el desarrollo de software, arquitectura de bases de datos, despliegue de aplicaciones y otras tecnologías clave.

## Secciones principales

- **Bases de Datos (SQL / NoSQL)**: Teoría, tipos de datos, normalización, arquitectura y operadores de conjuntos.
- **Contenedores (Docker)**: Flujos de publicación, comandos clave y orquestación con Docker Compose.

*(Documentación en constante crecimiento)*
